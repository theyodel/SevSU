# Почему блокноты сломаны и их трудно посмотреть?
Всё дело в **шапке блокнота**. Данная шапка нужна чисто для подписи кафедры, дисциплины, номера блокнота и прочей инфы. Для удобного просмотра блокнота можно выполнить одно из предложенных действий:
- Скачать блокнот и открыть его в своём редакторе кода (лучше всего в `Jupyter Notebook`)
- Скачать `.html` версию блокнота и просматривать её с помощью браузера
- Открыть блокнот в веб-версии VSCode от гитхаб (гайд ниже)

## Гайд: как открыть веб версию блокнота?
Всё супер легко и справится даже самоед, просто необходимо открыть интересующий вас блокнот и в адрессной строке браузера (это там где ссылка написана) заменить домен github.com на github.dev и всё!
